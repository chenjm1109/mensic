# 百分比堆叠柱状图

先把每个类别的各系列归一化成百分比，再堆叠成整根柱，强调构成比例。

## 要点

- **行归一化**：`百分比 = 数值 / 该类别数值之和 * 100`，每根柱高度恒为 100。
- **坐标范围**：`presentation.limits.y = [0, 110]` 给顶部留白。
- **配色**：系列颜色取 `tokens.color.palette`。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `bar_width` | number | 0.7 | 柱子宽度 |

## 库之间的差异

- **matplotlib**：透视后按行除以行和再堆叠。
- **Plotly / Altair**：先派生 `百分比` 列，再分别用 `barmode="stack"` /
  默认堆叠渲染。
