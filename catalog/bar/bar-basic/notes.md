# 基本柱状图

最基础的柱状图：用柱子高度表示类别数值，并按阈值给柱子分类着色。

## 要点

- **阈值着色**：低于 `low` 的柱子标为"过低值"，高于 `high` 的标为"过高值"，其余为"正常值"。
- **数值标签**：直接在柱内标注数值，省去对照坐标轴读数。
- **参考线**：两条虚线对应两个阈值，强化分类依据。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `low` | number | 10 | 过低值阈值 |
| `high` | number | 60 | 过高值阈值 |
| `show_labels` | bool | true | 是否显示数值标签 |

## 库之间的差异

- **matplotlib**：命令式，逐柱设置颜色，控制粒度最细。
- **Plotly**：交互式，鼠标悬停查看数值，可直接嵌入网页。
- **Altair**：声明式，通过派生"分类"列 + 颜色比例尺完成阈值着色，代码最短。
