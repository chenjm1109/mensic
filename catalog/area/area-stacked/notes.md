# 堆叠面积图

多条序列沿纵轴依次累积堆叠，同时展示总量变化与内部构成。数据由固定随机种子
（`seed=64`）的高斯叠加函数生成，共 8 条序列。

## 要点

- **累积堆叠**：各系列自下而上堆叠，顶层包络即总量曲线。
- **白色分割线**：在相邻层的分界处画白线，让层与层边界清晰可辨。
- **峰值标注**：对顶层包络做局部极大值检测，用点线 + 圆点标出峰位并标注数值。
- **配色**：取自 `params["tokens"]["color"]["palette"]`；序列多于调色板时循环复用。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `divider` | bool | true | 是否绘制层间白色分割线 |
| `show_peaks` | bool | true | 是否标注顶层包络的峰值 |

## 库之间的差异

- **matplotlib**：`stackplot` 一步堆叠；分割线与峰值用 `plot` / `text` 叠加。
- **Plotly**：`stackgroup="one"` 自动累积，交互悬停可读取数值。
- **Altair**：`mark_area` + `stack="zero"`；以白色描边充当分割线，单层 Chart 便于
  presentation 统一施加轴标题与范围（峰值标注仅 mpl / Plotly 提供）。
