# 百分比堆叠面积图

先把每个 x 处的数值归一化为百分比，再自下而上堆叠，突出总量恒定下的相对构成。
数据由固定随机种子（`seed=8`）的高斯叠加函数生成。

## 要点

- **百分比归一化**：每个 x 处所有系列之和为 100%，纵轴固定 0–100。
- **构成对比**：整体高度恒定，因此各层厚度直接反映占比变化。
- **白色分割线**：相邻层的分界线用白线区分。
- **配色**：取自 `params["tokens"]["color"]["palette"]`，序列多于调色板时循环复用。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `divider` | bool | true | 是否绘制层间白色分割线 |

## 库之间的差异

- **matplotlib**：在实现内 `y / y.sum(axis=0) * 100` 后 `stackplot`。
- **Plotly**：同样在实现内归一化，`stackgroup="one"` 堆叠，悬停显示百分比。
- **Altair**：用 pandas `groupby(x).transform("sum")` 计算百分比，`stack="zero"` 堆叠。
