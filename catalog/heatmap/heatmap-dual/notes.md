# 双指标热力图

每个网格被主对角线切成两个三角，左上三角表示"上方指标"、右下三角表示"下方指标"，在一张图里同时比较两套数值。

## 要点

- **三角网格**：用 `Polygon` 逐格绘制两个三角，形成沿对角线错开的双色块。
- **两套色带**：上方指标用 `tokens.color.sequential`（5 色），下方指标用 `tokens.color.diverging`（3 色），并用两条顶部横向色条分别标注。
- **动态文字色**：按归一化取值动态选择文字颜色，保证深浅背景下都可读。
- **数据来源**：由源 `07-double-value/upper_data.csv`、`lower_data.csv` 裁剪合并为单一长表 `data/dual_values.csv`（`行/列/上方指标/下方指标`），两个原始 CSV 亦保留在 `data/` 中。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `alpha` | number | 0.75 | 三角色块透明度 |
| `show_labels` | bool | true | 是否在格内显示数值 |

## 库之间的差异

- 仅提供 **matplotlib** 实现：需要逐格绘制两个三角形，Plotly / Altair 无对应的简单图元组合。
