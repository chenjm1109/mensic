# 表格型热力图

以网格色块表示二维矩阵，并在每个单元格内标注数值，兼具热力图与表格的功能。

## 要点

- **双向高斯 + 噪声**：数据由左下负峰、右上正峰两个二维高斯叠加，再叠加均匀噪声（seed=2），形成正负对比明显的矩阵。
- **单元格数值**：每个格子内标注整数，并按取值动态切换文字颜色（负值冷色、正值暖色、极端值白色）以保证可读性。
- **白色网格线**：以 minor tick 定位画白色分隔线，模拟表格线。
- **连续配色**：使用 `tokens.color.sequential`，右侧色条由实现绘制。
- **单元格编号**：行、列号从 1 开始。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `show_values` | bool | true | 是否在单元格内显示数值 |

## 库之间的差异

- **matplotlib**：`imshow` + minor grid + 逐格 `text`，控制力最强。
- **Plotly**：`go.Heatmap` 负责色块，数值用按颜色分组的 `go.Scatter(mode="text")` 叠加，实现动态文字色。
- **Altair**：`mark_rect` + `mark_text` 两层，派生"文本色"列驱动文字颜色，代码最简洁。
