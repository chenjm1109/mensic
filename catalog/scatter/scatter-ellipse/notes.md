# 带分布椭圆散点图

在分组散点的基础上，为每个类别叠加一个协方差椭圆，用来概括该组数据的
中心位置、离散程度与两个维度之间的相关性（椭圆倾斜方向即相关方向）。

## 要点

- **椭圆求解**：对每组 `(主成分1, 主成分2)` 求协方差矩阵，做特征分解，
  最大特征向量决定长轴方向，半轴长为 `n_std · √特征值`。
- **默认 2σ**：覆盖约 86% 的正态样本，可用参数 `n_std` 调整。
- **椭圆样式**：半透明填充 + 同色描边（matplotlib 用 `Ellipse` patch；
  Plotly 无 patch，用参数方程采样成 `fill="toself"` 的闭合折线）。
- **边缘投影**：点分别投到底部 `y_min` 与左侧 `x_min = min - 0.3`。
- **呈现规格**：标题 / 坐标轴标签 / 刻度 / 图例位置来自 `presentation`。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `point_size` | number | 100 | 散点面积 |
| `alpha` | number | 0.5 | 点的透明度 |
| `n_std` | number | 2.0 | 椭圆标准差倍数 |
| `show_projection` | bool | true | 是否绘制边缘投影刻度线 |

## 库之间的差异

- **matplotlib**：`matplotlib.patches.Ellipse` 直接绘制，最精确。
- **Plotly**：用特征分解结果采样为闭合曲线并填充，交互悬停显示坐标。

## 数据说明

原脚本用 `sklearn` 加载鸢尾花数据集并做主成分分析（PCA）得到二维坐标；
这里直接把已算好的 `主成分1, 主成分2, 类别`（150 行）裁剪复制进 `data/`，
实现因此不依赖 `sklearn`。
