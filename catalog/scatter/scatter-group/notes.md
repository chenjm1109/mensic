# 分组散点图

在基本散点图的基础上，按类别（`组别`）给点着色，用于比较多个组在两个
连续维度上的分布差异。同样在坐标轴边缘绘制各组的投影刻度线。

## 要点

- **分组着色**：按 `组别` 的首次出现顺序依次取 tokens 调色板颜色，
  保证跨库配色一致、分组顺序稳定。
- **投影刻度**：每组点分别投到底部（`y = 0`）与左侧（`x = 0`），
  刻度线用该组颜色，便于比较各组在单轴上的分布。
- **图例**：只列出分组，投影不进入图例（matplotlib 投影不设 `label`，
  Plotly 置 `showlegend=False`，Altair 三个图层共用同一颜色字段合并为一条图例）。
- **呈现规格**：标题 / 坐标轴标签 / 刻度 / 图例位置来自 `presentation`。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `point_size` | number | 100 | 散点面积 |
| `alpha` | number | 0.5 | 点的透明度 |
| `show_projection` | bool | true | 是否绘制边缘投影刻度线 |

## 库之间的差异

- **matplotlib**：逐组调用 `scatter`，最直观。
- **Plotly**：每组一条 trace，交互悬停显示分组与坐标。
- **Altair**：声明式，`color` 编码 `组别`，散点 + 两条 `mark_tick` 图层叠加。

## 数据说明

原脚本使用宽表 `X1,Y1,X2,Y2,X3,Y3`；这里整理为长表
`X轴, Y轴, 组别`（3 组 × 80 行），更贴合 `series` 角色与声明式绘图。
