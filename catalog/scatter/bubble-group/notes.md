# 分组气泡图

在基本气泡图基础上引入三个分组：**颜色**区分类别，**大小**编码数值，同时保留两轴地毯线。

## 要点

- **双重编码**：`类型` 映射到颜色，`大小` 映射到气泡面积，两个维度互不干扰。
- **按组地毯线**：每组在 `x=0` / `y=0` 处各画一排彩色短刻度，便于观察各组的边缘分布。
- **两个图例**：左上为类型图例，右上为尺寸图例（用中性色，避免与类型颜色混淆）。
- **只画 marks**：标题、轴标签、刻度间距由 `presentation` 施加。
- 数据由原脚本 `seed=7` 生成，三组共 120 个气泡固化到 `data/bubbles.csv`。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `point_alpha` | number | 0.5 | 气泡透明度 |
| `size_scale` | number | 1.0 | 气泡大小缩放系数 |

## 库之间的差异

- **matplotlib**：类型图例与尺寸图例分别用 `Line2D` 构造，`add_artist` 保留第一个图例。
- **Plotly**：每个类型一条 trace（颜色 + 图例），地毯线为短线段，尺寸图例为中性色占位 trace。
- **Altair**：`Color` + `Size` 双通道，自动生成两个图例；地毯线用 `mark_tick` 并按类型着色（关闭图例）。
