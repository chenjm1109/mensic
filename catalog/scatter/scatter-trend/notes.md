# 带趋势线散点图

对三组数据分别叠加不同形状的拟合曲线，展示"散点 + 趋势"的组合表达：

- `线性数据` → 一次线性拟合；
- `二次多项式数据` → 二次多项式拟合；
- `指数数据` → 指数拟合 `a·e^(bx)+c`。

## 要点

- **拟合形状由分组决定**：按 `组别` 名称选择拟合函数，曲线在每组 X 范围内
  取 100 个等距点绘制，虚线样式与散点同色。
- **指数拟合用纯 numpy 实现**：采用带步长回退的高斯-牛顿迭代求解
  `a·e^(bx)+c`，多组初值取最优，避免引入 `scipy` 依赖。
- **边缘投影**：三组点分别投到底部 / 左侧的 `-0.5` 位置。
- **呈现规格**：标题 / 坐标轴标签 / 刻度 / 图例位置来自 `presentation`。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `point_size` | number | 100 | 散点面积 |
| `alpha` | number | 0.5 | 点的透明度 |
| `show_projection` | bool | true | 是否绘制边缘投影刻度线 |

## 库之间的差异

- **matplotlib**：`scatter` + `plot`，逐组绘制，图例含数据与拟合共 6 项。
- **Plotly**：数据点与拟合线各一条 trace，可交互悬停。
- **Altair**：拟合曲线先在 Python 中算好再作为 `mark_line` 图层叠加，
  图例按 `组别` 合并为 3 项。

## 数据说明

原脚本用 `numpy.random.seed(42)` 生成三组各 80 条数据；这里用相同 seed
生成确定性 CSV（长表 `X轴, Y轴, 组别`），保证与原图一致。
