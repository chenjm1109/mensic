# 基本气泡图

散点图的扩展：除了 `X`、`Y` 两个位置维度外，再用**气泡面积**编码第三个数值维度 `大小`。

## 要点

- **气泡大小**：`s=大小`（matplotlib 的面积单位），适中透明度让重叠的气泡仍可分辨。
- **两轴地毯线**：在 `y=0` 与 `x=0` 处画一排短刻度，分别展示 `X`、`Y` 两个变量的一维分布（rug plot）。
- **尺寸图例**：用两个示例气泡说明"数值小 / 数值大"。
- **只画 marks**：标题、轴标签、刻度间距、图例位置由 `presentation` 施加。
- 数据由原脚本 `seed=1` 生成，100 个气泡固化到 `data/bubbles.csv`。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `point_alpha` | number | 0.5 | 气泡透明度 |
| `size_scale` | number | 1.0 | 气泡大小缩放系数 |

## 库之间的差异

- **matplotlib**：`scatter` 的 `s` 为面积；地毯线用 `marker="|" / "_"` 实现，尺寸图例用 `Line2D` 手工构造。
- **Plotly**：`marker.size` 为直径（按 `sqrt(面积)` 换算）；不支持稳定的竖/横线 marker symbol，地毯线改用短线段绘制，尺寸图例用空点占位 trace。
- **Altair**：用 `size` 通道编码大小，自动生成尺寸图例；地毯线用 `mark_tick` + `datum(0)` 叠加。因 Altair 适配器只对单层图施加 `presentation`，这里把数据列重命名为轴标题，使分层图仍显示中文轴名。
