# 单轴分组气泡图

横向排列的分组条带图：y 轴只放**分类**（五个分组），x 轴是数值，气泡大小再编码一个数值维度。

## 要点

- **单轴结构**：y 位置由分组顺序决定，分组本身写在分类轴标签上；x 为唯一数值轴。
- **分组着色**：五个分组依次取分类色板的前五种颜色。
- **尺寸图例**：用 `数值=20 / 300 / 500` 三个示例气泡说明面积含义。
- **只画 marks**：标题、x 轴标签、刻度间距由 `presentation` 施加。
- 数据由原脚本 `seed=1` 生成，五个分组各 30 个气泡固化到 `data/strip.csv`。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `point_alpha` | number | 0.5 | 气泡透明度 |
| `size_scale` | number | 1.0 | 气泡大小缩放系数 |

## 库之间的差异

- **matplotlib**：直接以分组字符串作为分类 y 轴，气泡颜色按组逐点给出；只保留横向网格以强调条带。
- **Plotly**：每个分组一条 trace 得到颜色与图例，y 轴为分类轴。
- **Altair**：`y=分组:N`（显式 `sort` 固定顺序）、`color` 编码分组、`size` 编码数值，单层图由 `presentation` 统一标题与轴标签。
