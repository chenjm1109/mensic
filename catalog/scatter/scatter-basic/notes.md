# 基本散点图

最基础的散点图：每个点代表一条观测，用点的位置表示两个连续变量的关系。
同时在横轴、纵轴边缘画出投影刻度线，方便读出每个点在两个维度上的分布。

## 要点

- **主散点**：`X轴` 对 `Y轴` 的散点，半透明以避免重叠点互相遮挡。
- **边缘投影**：把每个点的 X 坐标投到底部（`y = 0`）、Y 坐标投到左侧（`x = 0`），
  用细刻度线画出，相当于"单变量的地毯图（rug）"。
- **配色**：单色，取 `params["tokens"]["color"]["palette"][0]`。
- **呈现规格**：标题、坐标轴标签、主/次刻度间距、坐标标题全部来自 `meta.yaml` 的
  `presentation`，实现里不写死。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `point_size` | number | 100 | 散点面积（matplotlib 语义），Plotly 取平方根换算为直径 |
| `alpha` | number | 0.5 | 点的透明度 |
| `show_projection` | bool | true | 是否绘制坐标轴边缘的投影刻度线 |

## 库之间的差异

- **matplotlib**：`scatter` + 线型 marker（`"|"` / `"_"`）实现投影，控制最细。
- **Plotly**：交互式悬停读数；投影用 `line-ns` / `line-ew` 符号。
- **Altair**：声明式；散点与投影分层叠加（`mark_point` + `mark_tick`），
  因所有图层共用 `X轴` / `Y轴` 字段，坐标标题自动一致。
