# 半环饼图

只占用半圈（0~180°）的环形饼图，比整圆更轻盈，常用于仪表盘式版面。

## 要点

- **极坐标条形**：在 `projection: polar` 下用 `ax.bar` 绘制，每段的角度宽度与数值成正比（半环合计 π）。
- **环带半径**：`radius` 为内半径、`thickness` 为环厚，半径范围由 presentation 的 `limits.y` 约束。
- **刻度隐藏**：极坐标默认的网格、角度刻度与半径刻度与本图无关，已在实现中关闭。
- **图例在顶**：横向图例放在画布顶部，条形不注册 label 以免被通用图例逻辑改写位置。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `radius` | number | 20 | 环带内半径 |
| `thickness` | number | 10 | 环带厚度 |
| `show_labels` | bool | true | 是否在环带内显示百分比与数值 |

## 说明

该图依赖极坐标，Altair 不支持极坐标 / 径向图，故仅提供 matplotlib 实现。
