# 复合饼图

主饼图只保留少量大类；当某个「其它」大类仍包含较多子类时，把它拆到旁边的小环展开，
并用虚线框标出它对应的扇区，实现「主图 + 明细图」的组合。

## 要点

- **主环 + 明细环**：主环半径 `[ring_width, 2*ring_width]`，明细环 `[2.5*ring_width, 3*ring_width]`，中留一圈间隙。
- **按需展开**：`explode_index` 指定要展开的大类下标（默认 2，即「其它」），其余大类的子段留白不显示。
- **虚线关联**：一段点线环覆盖被展开大类的角度，跨过间隙连接主环与明细环。
- **顺时针布局**：matplotlib 设 `theta_direction=-1`、偏移 `-45°`，主环从右上开始顺时针排布。

## 数据契约

`data/hierarchy.csv` 为两层级明细，`主类别` / `子类别` / `数值` 三列；被展开大类的明细即其子类数值。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `ring_width` | number | 0.2 | 单环宽度 |
| `explode_index` | integer | 2 | 被展开的大类下标 |
| `show_labels` | bool | true | 是否显示内外环标签 |

## 说明

该图依赖极坐标，Altair 不支持极坐标 / 径向图，故仅提供 matplotlib 实现。
