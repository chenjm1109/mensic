# 嵌套饼图

内外两环的层级饼图：内环表示大类，外环把大类继续拆分为子类。类似缩略版旭日图。

## 要点

- **两环布局**：内环半径 `[ring_width, 2*ring_width]`，外环 `[2*ring_width, 2.5*ring_width]`，中心留白。
- **角度对齐**：内外环共用同一总角度 2π，子类的累计角度与所属大类对齐。
- **同族同色**：外环子类沿用其主类颜色并降低透明度，层级关系一眼可辨。
- **标签双层**：内环标大类名称与合计占比，外环标子类名称与各自占比。

## 数据契约

`data/hierarchy.csv` 为两层级明细，`主类别` / `子类别` / `数值` 三列；主类别的总量由子类数值求和得到。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `ring_width` | number | 0.2 | 单环宽度，控制环厚与中心留白 |
| `show_labels` | bool | true | 是否显示内外环标签 |

## 说明

该图依赖极坐标，Altair 不支持极坐标 / 径向图，故仅提供 matplotlib 实现。
