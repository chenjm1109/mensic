# 基本饼图

最基础的饼图：用扇形面积表示各类型数值占整体的比例。

## 要点

- **占比编码**：扇形圆心角与数值成正比，`占比 = 数值 / 总和`。
- **扇区标签**：直接标注 `百分比% | 绝对值`，省去对照坐标轴。
- **统一配色**：颜色来自设计令牌的 `palette`，与前 5 个类型一一对应。
- **图例在左**：matplotlib 把图例放到画布左侧，避免遮挡扇形。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `show_labels` | bool | true | 是否在扇区内显示百分比与数值 |
| `start_angle` | number | 0 | 起始角度（matplotlib / Plotly 生效） |

## 库之间的差异

- **matplotlib**：`ax.pie` 一次完成扇形、百分比文本与图例句柄。
- **Plotly**：`go.Pie` 交互式，悬停显示标签 / 数值 / 百分比，`hole=0` 即实心饼。
- **Altair**：`mark_arc` + `theta` 编码，声明式；起始角不可配置，扇形默认从 12 点方向开始。
