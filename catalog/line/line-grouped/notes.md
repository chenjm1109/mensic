# 分组折线图

在同一坐标系内用多条折线对比多个国家在同一时间轴上的走势。

## 要点

- **多序列对比**：四个国家各画一条折线，颜色来自 `tokens.color.palette` 分类色板。
- **阶段高亮**：2000–2014 年用全高竖向色带标出「全球化时期」，两端画虚线并加文字。
- **历史高位标注**：在喀麦隆 1993 年的峰值处加实心点与文字，突出个别异常点。
- **单位换算**：数据层已把 GDP 换算为「亿美元」。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `line_width` | number | 3 | 折线线宽 |
| `marker_size` | number | 5 | 节点标记大小 |

## 数据

- `data/gdp.csv`：年份 + `df.columns[3:7]` 四国（博茨瓦纳、布基纳法索、布隆迪、喀麦隆），来自 `src/06-line/dataset1.csv` 裁剪。

## 库之间的差异

- **matplotlib**：`axvspan` 做全高色带，逐列 `plot`。
- **Plotly**：`add_vrect` 做色带，`add_vline` 画边界，图例按适配器规则置于左上。
- **Altair**：宽表 `melt` 成长表后按 `color` 通道着色；分层图显式声明轴标题与 scale domain。
