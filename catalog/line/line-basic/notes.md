# 标准折线图

最基础的折线图：用一条折线表示数值随连续维度（年份）的变化，并对关键阶段与节点做高亮。

## 要点

- **单序列趋势**：只画一条线，节点用空心圆标记，避免与分组折线图混淆。
- **区间高亮**：在两个时期（发展期 / 衰退期）将折线下方填色，并在两端画虚线，直观呈现阶段划分。
- **关键节点**：衰退开始、衰退结束、2008 年三个节点用实心点 + 文字标注。
- **单位换算**：原始数据的 GDP 为美元，这里在数据层就换算成「亿美元」，坐标轴刻度因此是普通数字。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `line_width` | number | 3 | 折线线宽 |
| `marker_size` | number | 6 | 节点标记大小 |

## 数据

- `data/gdp.csv`：年份 + 阿尔及利亚 GDP（亿美元），来自 `src/06-line/dataset1.csv` 裁剪。
- 原脚本 `01.py` 使用 `data[:, 1]` 单列，因此这里只保留单序列（阿尔及利亚）。

## 库之间的差异

- **matplotlib**：命令式，`fill_between` 做折线下方填充，控制粒度最细。
- **Plotly**：交互式；用 `fill="tozeroy"` 复刻区间填充，`add_vline` 画边界虚线，悬停查看数值。
- **Altair**：声明式分层；`mark_area` + `mark_rule` + `mark_line` 组合。
  注意：Altair 分层图无法被适配器注入轴标题 / 值域，故在编码里显式声明与 `presentation` 对齐的标题与 scale domain。
