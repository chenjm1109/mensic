# 双坐标折线图

用左、右两条纵轴同时呈现量纲不同的两条序列，避免因数量级差异而互相压扁。

## 要点

- **双轴**：左轴为经济（亿美元），右轴为人口（万人）；两条线各自独立缩放。
- **轴色区分**：左轴刻度与脊线用青色、右轴用红色，与线条颜色一致，便于辨认归属。
- **内战时期高亮**：1989–2003 年画阴影色带并标注起止年份。
- **节点标注**：在内战开始（1989）与 1991 年人口谷值处标注数值。

## 实现边界（重要）

`presentation` 统一控制左轴（`ax`）的标题 / 范围 / 刻度 / 图例；
`ax.twinx()` 产生的右轴无法被 `presentation` 覆盖，因此**右轴的值域、刻度颜色与图例在实现内设置**，这是双坐标专题的必要例外。

## 可调参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `line_width` | number | 3 | 折线线宽 |
| `marker_size` | number | 5 | 节点标记大小 |

## 数据

- `data/liberia.csv`：年份 + 经济（亿美元，取自 `src/06-line/dataset1.csv` 的 Liberia 列）+ 人口（万人，取自 `dataset2.csv` 中 `country_name == "Liberia"` 的行），均为 1960–2021。
- 只抽取了 Liberia 一国两列，未复制 541KB 的整份 `dataset2.csv`。

## 库之间的差异

- 仅提供 **matplotlib** 实现。双坐标（twin axes）在 Plotly/Altair 中需额外的多轴布局支持，与本专题「一图多轴」的简洁契约不符，故不实现。
